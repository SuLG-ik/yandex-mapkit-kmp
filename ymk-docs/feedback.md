`MapKit` · `Guide` — [оригинал](https://yandex.ru/maps-api/docs/mapkit/feedback.html)

Если при работе с MapKit у вас возникли трудности или замечания, пожалуйста, сообщите нам об этом. Выберите нужную категорию для обращения:

## Вопросы по использованию MapKit

Если ваш код не работает или вы не знаете, как решить свою задачу:

|   |   |
| --- | --- |
| ![](https://yandex.ru/maps-api/docs/mapkit/_assets/q_a.png) | 1. Прочитайте [часто задаваемые вопросы](faq.md). Возможно, раздел содержит ответ на ваш вопрос. |

|   |   |
| --- | --- |
| ![](https://yandex.ru/maps-api/docs/mapkit/_assets/stack-overflow.png) | 2. Поищите ответ в репозиториях GitHub для MapKit [Android](https://github.com/yandex/mapkit-android-demo/issues?utf8=%E2%9C%93&q=is%3Aissue) или [iOS](https://github.com/yandex/mapkit-ios-demo/issues?utf8=%E2%9C%93&q=is%3Aissue).<br>Если вы не нашли свой вопрос, задайте его там. Прежде чем публиковать вопрос, внимательно ознакомьтесь со статьей [Как задавать хорошие вопросы](https://ru.stackoverflow.com/help/how-to-ask). |

> [!NOTE] Примечание
> Также вы можете поискать ответ в сообществе [API Карт на Stack Overflow](https://ru.stackoverflow.com/questions/tagged/yandex-maps-api) и [Клубе API Карт](https://yandex.ru/blog/mapsapi). Клуб доступен только для чтения — все технические вопросы следует задавать в GitHub и Stack Overflow.

## Ошибка в MapKit

Если вы обнаружили ошибки в MapKit, создайте issue в GitHub репозитории с примерами MapKit для [Android](https://github.com/yandex/mapkit-android-demo/issues) или [iOS](https://github.com/yandex/mapkit-ios-demo/issues), в зависимости от используемой вами платформы. По возможности приведите фрагмент кода, в котором возникает ошибка. Мы будем рады помочь вам.

Если вы нашли ошибку в документации, пожалуйста, заполните форму обратной связи.
