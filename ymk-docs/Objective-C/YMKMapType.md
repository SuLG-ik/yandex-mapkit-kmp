# YMKMapType

`IOS` · `Objective-C` · `Enum` — [оригинал](https://yandex.ru/maps-api/docs/mapkit/Objective-C/YMKMapType.html)


The type of map displayed.

## Summary

### Enum cases

```objectivec
YMKMapTypeNone
```

Do not use any of the predefined maps

```objectivec

```

```objectivec
YMKMapTypeSatellite
```

Allowed only for Yandex apps Default satellite map

```objectivec
YMKMapTypeHybrid
```

Allowed only for Yandex apps Satellite map with roads, placemarks and labels

```objectivec
YMKMapTypeVectorMap
```

Vector map
