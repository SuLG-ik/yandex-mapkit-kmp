# Пересборка локальной копии документации

Скрипты, которыми снята копия документации в `ymk-docs`. Нужны, чтобы обновить её под новый релиз SDK.

Требования: Python 3 и `lxml` (единственная внешняя зависимость).

Обновление запускается вручную и очень редко — под релиз MapKit. Готовый порядок действий с проверками оформлен скиллом `/yml-update-original-docs`.

## Как обновить документацию

Все команды выполняются из этого каталога — рабочие файлы (`toc.js`, `hrefs.json`, `cache/`, `infos.json`) создаются здесь же.

1. Снять актуальное оглавление сайта:

   ```bash
   python3 fetch_toc.py
   ```

   Пишет `toc.js` и `hrefs.json` (список всех страниц с путём в дереве навигации).

2. Скачать страницы в кеш (10 параллельных потоков, повторные запуски докачивают только недостающее):

   ```bash
   python3 fetch_all.py
   ```

   Каждая страница сохраняется в `cache/<путь>.json` как `{href, toc_path, title, sourcePath, html}`. Контент берётся из `window.__DATA__.data.html` — сервер отдаёт готовый HTML, JS-рендер не нужен.

3. Сконвертировать кеш в Markdown:

   ```bash
   python3 build_docs.py ..
   ```

4. Перестроить индексы (`README.md`, `SUMMARY.md`, `INDEX-*.md`, `README.md` в каталогах пакетов):

   ```bash
   python3 build_indexes.py ..
   ```

## Проверки

```bash
python3 validate2.py ..
```

Сверяет каждый `.md` с исходным HTML: все значащие слова оригинала должны присутствовать в результате. Печатает процент покрытия и список проблемных страниц.

```bash
python3 link_check.py ..
```

Проверяет, что каждая относительная ссылка между страницами указывает на существующий файл.

## Ручная сверка одной страницы

```bash
python3 showpage.py Objective-C/YMKAddressBook.html
```

Печатает текст живой страницы с оригинала; адреса ссылок выводятся в тексте как ` →(адрес)`. Удобно сравнивать с локальным `.md` глазами.

## Что делает конвертер

`h2md.py` переводит HTML в Markdown по правилам:

- `<samp>` с сигнатурой — в блок кода с подсветкой (`objectivec`, `swift`, `java`); подряд идущие фрагменты одной многострочной сигнатуры склеиваются в один блок;
- одноколоночные таблицы-обёртки разворачиваются в блок кода плюс текст описания, многоколоночные остаются GFM-таблицами;
- `<div class="yfm-note">` — в `> [!NOTE]` / `> [!WARNING]`, `<details class="yfm-cut">` — в жирный заголовок с содержимым;
- ссылки на страницы документации пересчитываются в относительные пути к локальным `.md`, ссылки на изображения остаются абсолютными;
- служебная разметка (кнопки копирования, SVG-иконки, скрытые якоря) отбрасывается.
