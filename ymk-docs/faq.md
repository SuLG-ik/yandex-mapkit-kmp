# Часто задаваемые вопросы

`MapKit` · `Guide` — [оригинал](https://yandex.ru/maps-api/docs/mapkit/faq.html)

## Общие вопросы

**Хочу следить за лимитом запросов. Есть ли в MapKit специальный инструмент?**

Статистику использования MapKit можно найти в [Кабинете разработчика](https://developer.tech.yandex.ru/).

**Какие типы карт доступны в MapKit?**

В MapKit доступны только карты с типом «схема» и пользовательские слои карт.

**Могу ли я использовать MapKit в своем Xamarin приложении?**

На данный момент Xamarin приложения не поддерживаются.

**Могу ли я использовать MapKit в своем React Native приложении?**

На данный момент приложения, написанные на React Native, не поддерживаются.

**Как можно проанализировать проблему с MapKit у конкретных пользователей моего приложения?**

Для того чтобы на стороне Яндекс можно было проанализировать проблему в работе MapKit SDK у конкретных пользователей, необходимо перед инициализацией MapKit указывать уникальный идентификацитор пользователя с помощью метода setUserId в MapKit SDK.

## Технические вопросы

**Почему вместо карты отображается пустая сетка?**

Проверьте, что установлен правильный ApiKey и вы вызываете метод MapKit.onStart().

**Можно ли использовать векторные изображения в качестве маркеров в MapKit?**

Векторные изображения не поддерживаются.

**Есть ли в MapKit возможность создать статическую карту?**

В MapKit есть возможность отключить пользовательское взаимодействие с картой с помощью метода `setNoninteractive` для Android, либо `setNonInteractive` для iOS.

**Есть ли в MapKit встроенные элементы управления?**

Элементы управления нужно реализовывать самостоятельно.

**Можно ли использовать произвольный объект в качестве метки на карте?**

На данный момент такой возможности нет.

**Как подключить MapKit для iOS без использования CocoaPods?**

1. Найти в [репозитории CocoaPods](https://github.com/CocoaPods/Specs) файл `YandexMapKit.podspec.json`.
2. Скачать артефакт сборку через ссылку из поля source:

   ```
   curl --remote-name https://maps-ios-pods-public.s3.yandex.net/YandexMapKit-3.3.1.framework.zip
   ```
3. Распаковать полученный архив.
4. Полученный framework можно использовать в приложении.

**Как задать локаль в приложении?**

Чтобы задать локаль, используйте метод `I18nManagerFactory.setLocale` для Android или метод `YRTI18nManagerFactory setLocaleWithLanguage` для iOS.
