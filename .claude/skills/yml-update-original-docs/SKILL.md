# Обновление локальной копии документации MapKit

## Когда это запускать

Только вручную и только по явной просьбе. Штатная частота — раз в несколько месяцев, когда в MapKit вышла заметная версия и локальная копия ощутимо разошлась с сайтом.

Не запускай этот скилл сам по себе. Ни один из этих поводов не является основанием:

- пользователь задал вопрос по API MapKit — просто читай `ymk-docs/`;
- в `gradle/libs.versions.toml` поднялась версия MapKit;
- кто-то заметил расхождение на одной странице — проверь её вручную через `showpage.py`, полная пересборка ради одной страницы не нужна;
- давно не обновляли.

Скилл переписывает больше 2000 файлов в `ymk-docs/`, поэтому запускать его без явной просьбы нельзя.

## Что делает

Снимает документацию заново с `https://yandex.ru/maps-api/docs/mapkit/` и полностью перезаписывает `ymk-docs/`. Формат страниц, структура каталогов и индексы остаются прежними — меняется только содержимое под актуальный релиз SDK.

Сайт отдаёт готовый HTML внутри `window.__DATA__`, а полное оглавление лежит в `toc.js`, поэтому браузер не нужен: страницы качаются напрямую и конвертируются скриптом. Никакой модели в конвейере нет — результат детерминирован.

## Порядок действий

Требуется Python 3 с `lxml`. Быстрый путь — один прогон всего конвейера с проверками:

```bash
python3 ymk-docs/_tools/bootstrap.py --force --refresh --validate
```

`--refresh` удаляет кеш `_tools/cache/`, поэтому запускай эту форму только с явного согласия пользователя. Дальше — те же шаги по отдельности, если нужно вмешаться в середину; все команды выполняются из `ymk-docs/_tools`.

1. Убедись, что изменения в `ymk-docs/` сохранены — шаги 3 и 4 перезаписывают файлы без спроса. Сам каталог не под версионным контролем (`ymk-docs/*` игнорируется, кроме `_tools`), поэтому `git status` пропажу или порчу страниц не покажет.

2. Снять актуальное оглавление:

   ```bash
   cd ymk-docs/_tools && python3 fetch_toc.py
   ```

   Печатает число страниц в оглавлении. Сравни его с предыдущим значением из `ymk-docs/README.md`: сильное расхождение означает, что структура сайта поменялась — тогда сначала разберись, что именно изменилось, и только потом продолжай.

3. Скачать страницы в кеш:

   ```bash
   cd ymk-docs/_tools && python3 fetch_all.py
   ```

   Десять параллельных потоков, около двух минут. Кеш лежит в `_tools/cache/`; повторный запуск докачивает только недостающее. В конце печатается `DONE N/N` и число ошибок — оно должно быть нулевым.

   Чтобы получить именно свежие страницы, а не старый кеш, каталог `_tools/cache/` перед запуском нужно убрать. Это единственный шаг, где удаляются данные — попроси пользователя выполнить удаление самостоятельно и дождись подтверждения.

4. Собрать Markdown и индексы:

   ```bash
   cd ymk-docs/_tools && python3 build_docs.py .. && python3 build_indexes.py ..
   ```

5. Проверить результат:

   ```bash
   cd ymk-docs/_tools && python3 validate2.py .. && python3 link_check.py ..
   ```

   Ожидается `coverage: 100.000000%`, `problem pages: 0` и `broken: 0`. Любое другое значение — повод разбираться, а не коммитить.

6. Показать пользователю сводку: сколько стало страниц, что изменилось в структуре, результаты проверок. Git здесь не помощник — каталог не отслеживается; чтобы увидеть дельту, снимай список файлов (`find ymk-docs -name '*.md' | sort`) до и после и сравнивай его `diff`-ом.

## Если проверки не сошлись

- **Покрытие меньше 100%** — конвертер не справился с новой разметкой. Найди проблемные страницы в выводе `validate2.py`, посмотри их исходный HTML в `_tools/cache/` и поправь `_tools/h2md.py`. После правки перезапусти шаги 4 и 5.
- **Есть битые ссылки** — либо на сайте появились ссылки нового вида, либо страница исчезла из оглавления, оставшись целью ссылок. Посмотри список из `link_check.py` и реши по ситуации.
- **Страница выглядит странно** — сверь её с оригиналом:

  ```bash
  cd ymk-docs/_tools && python3 showpage.py 'Objective-C/YMKAddressBook.html'
  ```

  Скрипт печатает текст живой страницы; адреса ссылок выводятся прямо в тексте как ` →(адрес)`. Учти, что часть дефектов есть в самом оригинале (например, заголовок «Constuctors» с опечаткой на сотнях страниц) — их копия воспроизводит намеренно, исправлять не нужно.

## Границы

Не коммить и не пушь результат без явной просьбы. Не трогай `docs/` — это отдельная документация репозитория, к копии MapKit отношения не имеющая.
